These files are **frozen marketing copy from the Vestige v2.0 "Cognitive Leap" launch**. They preserve what was announced at the time and intentionally are *not* kept in lockstep with the codebase.

| File | Audience | Frozen at |
|------|----------|-----------|
| [`blog-post.md`](blog-post.md) | Technical blog readers | v2.0 announcement |
| [`show-hn.md`](show-hn.md) | Hacker News submission + comments | v2.0 announcement |
| [`demo-script.md`](demo-script.md) | Live demo / video script | v2.0 announcement |

Numbers that change between releases (line counts, test counts, MCP tool counts, stage counts) reflect the launch snapshot, not the current state.

For the **current** numbers and architecture, always defer to:

- The root [`README.md`](../../README.md) for tools, modules, and benchmarks.
- [`ARCHITECTURE.md`](../../ARCHITECTURE.md) for the live pipeline description.
- [`AGENTS.md`](../../AGENTS.md) for the canonical MCP tool catalog.
- [`CHANGELOG.md`](../../CHANGELOG.md) for the timeline of changes since launch.

Storage paths in these files were corrected post-launch (the original copy contained an aspirational `~/.vestige/vestige.db` path that never matched the implementation), but otherwise the prose is intentionally untouched.
